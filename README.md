# Digital Waterfall

An interactive 3D waterfall built with Three.js. Glowing strands pour down a wall, flow over a rock, and fan out across the floor.

- Hover to stir a swirl into the flow; swirls drift downstream and thin the strands as they pass.
- Click for a big whirlpool.
- Drag to orbit, scroll to zoom.

Everything lives in `index.html`. Open it in a browser, or view it live on GitHub Pages.
